# Bưu Điện Mây ☁️

> Một chút dễ thương đang trên đường tới bạn.

Minigame chúc mừng ngày Phụ nữ Việt Nam 20/10, thiết kế cho điện thoại. Người chơi kéo đám mây shipper để hứng mochi, bông hoa và ngôi sao, rồi mở bưu kiện để nhận thiệp chúc mừng có tên mình.

## Cá nhân hóa

Thêm tên người nhận vào link:

```
https://hoangvh238.github.io/huyhoang2010/?name=Tiên
```

Không có `name` thì game gọi người nhận là "bạn".

## Chạy ở máy

```bash
python -m http.server 5199
```

Rồi mở `http://localhost:5199/?name=Tiên`.

HTML/CSS/JS thuần, không cần build. Âm thanh trong `sfx/` được tạo bằng ElevenLabs.
